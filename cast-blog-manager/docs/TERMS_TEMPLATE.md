## 第1条（適用）

本規約は、〔事業者名〕（以下「当社」）が提供するキャストブログ更新管理ツール
「cast-blog-manager」（以下「本サービス」）の利用条件を定めるものです。
契約者（以下「利用者」）は、本規約に同意のうえ本サービスを利用するものとします。

## 第2条（利用契約の成立）

利用者が当社所定の方法により申し込み、当社がこれを承諾した時点で
利用契約が成立します。

## 第3条（提供形態）

1. 本サービスは、〔買い切り／月額〕形式で提供します。
2. 本サービスは利用者ごとに個別に構築・提供され、
   他の利用者とデータを共有しません。
3. 本サービスの稼働に必要なホスティング、データベース、
   LINE公式アカウントの費用および契約は、〔当社／利用者〕が負担・管理します。

## 第4条（利用者の義務）

利用者は、以下を自己の責任で行うものとします。

1. 管理アカウントの ID・パスワードの管理
2. 従業員およびキャストに対する、本サービスの利用目的の説明と同意の取得
3. 本サービスに登録する情報の正確性の確保
4. 個人情報保護法その他の関係法令の遵守

## 第5条（禁止事項）

利用者は、以下の行為を行ってはなりません。

1. 本サービスのソースコードを第三者に開示、再配布、販売、貸与すること
2. 本サービスを利用して第三者向けにサービスを提供すること
3. リバースエンジニアリング、逆コンパイル、逆アセンブル
4. 法令または公序良俗に違反する行為
5. 本サービスの運営を妨害する行為

## 第6条（本サービスの内容および制限）

1. 本サービスは、キャストのブログ更新状況を **記録・可視化・通知** する
   管理ツールです。
2. **本サービスは、外部サイト（ポケパラ等）への自動投稿、自動ログイン、
   スクレイピングを一切行いません。** 更新記録は、キャスト本人による
   LINE 経由の自己申告、または店舗スタッフによる手入力のみに基づきます。
3. 本サービスに記録された更新実績は、利用者の運用に基づく自己申告値であり、
   当社は外部サイト上の実際の投稿との一致を保証しません。

## 第7条（LINE 通知に関する制限）

1. LINE 通知は LINE Messaging API を利用します。
2. LINE社のプランに応じた送信数の上限があり、上限を超えた通知は
   送信されません。上限の管理は利用者の責任で行うものとします。
3. キャストが LINE公式アカウントをブロックした場合、通知は届きません。
4. LINE社のサービス仕様変更・障害により通知が遅延・不達となる場合があります。

## 第8条（サポート）

1. 当社は、〔平日10:00〜18:00〕の時間帯において、
   〔メール〕によるサポートを提供します。
2. 以下はサポートの対象外とします。
   - 利用者による改変が原因の不具合
   - 外部サービス（LINE、ホスティング事業者等）に起因する障害
   - 利用者の通信環境・端末に起因する問題

## 第9条（データの取り扱いおよびバックアップ）

1. 本サービスに登録されたデータの管理責任は利用者にあります。
2. 当社は〔　〕の頻度でバックアップを取得しますが、
   データの完全な復旧を保証するものではありません。
3. 利用契約の終了時、当社は利用者の求めに応じてデータを
   〔CSV形式〕で提供し、その後〔　〕日以内に消去します。

1. 当社は、本サービスが利用者の特定の目的に適合すること、
   無中断・無誤作動で稼働することを保証しません。

# 骨格診断 × パーソナルカラー診断

25の質問に答えると、**骨格タイプ**（ストレート／ウェーブ／ナチュラル）と**パーソナルカラー**（イエベ春／ブルベ夏／イエベ秋／ブルベ冬）を同時に診断し、似合う素材・シルエット・色・メイクまで提案する Web アプリです。

ビルド不要・依存パッケージゼロの静的サイトなので、`index.html` をブラウザで開くだけで動きます。

```
open body-color-diagnosis/index.html      # macOS
xdg-open body-color-diagnosis/index.html  # Linux
```

## できること

| | 内容 |
| --- | --- |
| 骨格診断 | 12問。首・鎖骨・手首の骨の断面・肌の質感など、判別力の高い設問に重み付け（weight 2）をして採点します |
| パーソナルカラー診断 | 13問。4シーズンへの配点ベクトルを合算し、**ベース／明度／清濁**の3軸の偏りも百分率で表示します |
| 掛け合わせアドバイス | 3タイプ × 4シーズン = 12通りそれぞれに、具体的な着こなしの指針を用意しています |
| セカンドシーズン | 2位のシーズンも提示。1位との差が小さいときはミックスタイプである旨を注記します |
| 結果の共有 | 回答が URL のハッシュ（`#s=...&c=...`）に入るので、リンクを送るだけで同じ結果を再現できます |
| 結果のコピー | プレーンテキストの要約をクリップボードにコピーできます |
| 印刷 / PDF 保存 | 印刷用のスタイルを別途あてています |
| 途中保存 | 回答は `localStorage` に保存され、次回「前回の続きから」で再開できます。サーバー送信は一切ありません |

キーボード操作にも対応しています（`1`〜`4` で選択、`←`/`→` でフォーカス移動、`Backspace` で前の設問へ）。ライト／ダークの両テーマを用意し、OS 設定に追従しつつ手動切替もできます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み。イントロ / 設問 / 結果の3ビュー |
| `styles.css` | デザイントークン（色・書体・寸法）とコンポーネント |
| `data.js` | 設問、タイプ別のアドバイス、色見本、掛け合わせ文言。**内容を直すのはほぼここだけ** |
| `scoring.js` | 採点ロジック。画面から独立していて Node からも呼べる |
| `app.js` | 画面描画、状態管理、保存・共有 |
| `test.js` | データと採点の検証（外部依存なし） |
| `build.js` | 単一ファイル版の書き出し |
| `dist/` | 生成物。`index.html`（配布用の完全な HTML）と `embed.html`（既存ページ埋め込み用の断片） |

`data.js` と `scoring.js` は、ブラウザではグローバル変数として、Node では `module.exports` として同じオブジェクトを返すようにしてあります。ES モジュールにしていないのは、`file://` で直接開いたときに CORS でブロックされるのを避けるためです。

## 開発

```bash
node body-color-diagnosis/test.js    # データと採点の検証（638件のチェック）
node body-color-diagnosis/build.js   # dist/index.html と dist/embed.html を再生成
```

`test.js` は次を検証します。

- 全タイプ・全シーズンに必要なアドバイス項目がそろっているか
- 設問 id の重複、選択肢の欠け、未知のシーズン名、hex の書式
- 骨格の各設問に3タイプすべての選択肢があるか
- 3軸が4シーズンを過不足なく二分しているか
- 12通りの掛け合わせがすべて存在するか
- **あるタイプに寄せて回答したら、そのタイプが1位になるか**（骨格・カラーとも）
- 未回答が混ざっても採点が壊れないか、軸の割合が必ず合計100%になるか

設問やアドバイスを増やしたら `test.js` を流してください。設問数を変えても、テストと画面は自動的に追従します（`index.html` の初期表示 `1 / 25` だけは静的な値なので、気になる場合は書き換えてください）。

## 公開する

`dist/index.html` は CSS も JS も埋め込み済みの1ファイルなので、そのままどこにでも置けます。GitHub Pages で公開する場合は、このディレクトリをそのまま公開対象にすれば `index.html` が動きます。

## 注意

自己申告のアンケートに基づく簡易診断です。骨格もパーソナルカラーも、本来はプロが自然光の下でドレープを当てて判定します。結果が納得できないときは、上位2位のタイプを両方試してみるのがおすすめです。
